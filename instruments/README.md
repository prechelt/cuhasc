# README.md in `instruments/`

The actual questionnaires in their many translations live in
`cuhasc/data/instruments`, so that they become part of the `cuhasc` installable package.

The present directory contains only ancillary material for and from the development process.
The most notable of these are the LLM's notes from each translation process,
to be found in `translation-notes/notes-en-*.md`.
